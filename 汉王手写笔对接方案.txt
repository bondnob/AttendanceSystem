======================================================
        汉王手写笔与考勤系统对接方案
======================================================

一、对接原理
------------------------------------------------------
不需要后端 WebSocket。汉王手写笔的驱动程序会在客户端电脑上自动启动
一个本地 WebSocket 服务（ws://127.0.0.1:29999/），前端 JS 直接连接即可。

流程如下：

  [汉王手写笔硬件]
       ↓
  [HWHTTPServ 驱动服务, 端口29999]
       ↓
  [浏览器 JS WebSocket]
       ↓
  [签名图片 base64]
       ↓
  [Spring Boot REST API 保存]


二、前置条件
------------------------------------------------------
1. 在使用手写笔的电脑上安装驱动 HWSetup-2.7.80_20260415.exe
2. 驱动安装后每次开机自动启动 HWHTTPServ 服务
3. 如果是 Win10 系统，建议以管理员权限运行"禁用Win10快速启动.bat"，
   避免快速启动导致服务异常


三、前端集成代码
------------------------------------------------------

将压缩包中的 sign.js 引入前端页面，然后按以下流程调用：

--- 1. 连接签名服务 ---

sign.connectWebSocket(function(connected) {
    if (connected) {
        console.log('签名板服务已连接');
    } else {
        console.log('签名板服务未启动，请检查驱动');
    }
});

--- 2. 检测设备状态 ---

sign.getDeviceStatus(function(res) {
    if (res.msgID == 0) {
        console.log('设备已连接，宽高比：' + res.aspectRatio);
    }
});

--- 3. 打开设备开始签名 ---

sign.startSignParams.nWidth = 500;
sign.startSignParams.nHeight = 300;
sign.startSignParams.nImageWidth = 250;    // 输出图片宽度
sign.startSignParams.nImageHeight = 150;   // 输出图片高度
sign.startSignParams.penColor = "000000";  // 笔迹颜色
sign.startSignParams.nConfirmTimeout = 30; // 签名确认超时30秒

sign.startSign(function(res) {
    if (res.msgID == 0) {
        console.log('设备已打开，等待签名...');

        // 4. 注册签名完成回调
        sign.getSign(function(signRes) {
            if (signRes.msgID == 0) {
                // signRes.message 就是 base64 PNG 图片数据
                var base64Image = signRes.message;
                // 5. 上传到后端
                uploadSignature(base64Image);
            }
        });
    }
});

--- 6. 上传签名到考勤系统后端 ---

function uploadSignature(base64Data) {
    // 将 base64 转为 File 对象
    var byteString = atob(base64Data.split(',')[1] || base64Data);
    var ab = new ArrayBuffer(byteString.length);
    var ia = new Uint8Array(ab);
    for (var i = 0; i < byteString.length; i++) {
        ia[i] = byteString.charCodeAt(i);
    }
    var blob = new Blob([ab], { type: 'image/png' });
    var file = new File([blob], 'signature.png', { type: 'image/png' });

    var formData = new FormData();
    formData.append('signatureFile', file);
    formData.append('applicantType', 'APPLICANT'); // 或 TEAM_LEADER 等

    fetch('/api/leaves/' + leaveId + '/handwritten-signature', {
        method: 'POST',
        headers: { 'Authorization': 'Bearer ' + token },
        body: formData
    }).then(res => res.json()).then(data => {
        console.log('签名上传成功', data);
    });
}

--- 7. 签名完成后关闭设备 ---

sign.endSign(function(res) {
    console.log('设备已关闭');
});


四、与现有系统的结合点
------------------------------------------------------
项目已有签名上传的 REST 接口：

  POST /api/leaves/{leaveId}/handwritten-signature
  - 接收手写签名图片（HandwrittenSignatureDto）
  - 支持类型：APPLICANT（请假人）、APPLICANT_DATE（请假人日期）、TEAM_LEADER（班组长）

只需要在前端页面加入手写笔调用逻辑，拿到 base64 图片后转成文件，
调用已有的接口上传即可，后端基本不需要改动。


五、汉王 WebSocket API 速查
------------------------------------------------------

连接地址：ws://127.0.0.1:29999/

1) 打开设备（开始签名）
   发送：{"HWPenSign":"HWInitialize","key":"...","title":"请在签字板上签名",
          "showDialog":"1","nOrgX":"-1","nOrgY":"-1","nWidth":"500","nHeight":"300",
          "nImageWidth":"-1","nImageHeight":"-1","nConfirmTimeout":"30","penColor":"000000"}
   返回：{"HWPenSign":"HWInitialize","errorID":0,"error":"","message":"打开成功"}

2) 获取手写签名结果（签字确认后触发）
   接收：{"HWPenSign":"HWGetSign","errorID":0,"error":"","type":"base64",
          "message":"data:image/png;base64,iVBORw0KGgo..."}

3) 结束签名（关闭设备）
   发送：{"HWPenSign":"HWFinalize"}
   返回：{"HWPenSign":"HWFinalize","errorID":0,"error":"","message":"成功"}

4) 获取设备连接状态
   发送：{"HWPenSign":"HWGetDeviceStatus"}
   返回：{"HWPenSign":"HWGetDeviceStatus","errorID":0,"error":"",
          "deviceName":"ESP503B","message":"设备连接正常","aspectRatio":"16:9"}

5) 获取操作系统类型
   发送：{"HWPenSign":"HWGetOS"}
   返回：{"HWPenSign":"HWGetOS","errorID":0,"error":"","type":"Windows 10 专业版64位",
          "message":"ok"}


六、HWInitialize 参数说明
------------------------------------------------------
参数名           必选  说明
------------------------------------------------------
key              是    驱动授权密钥，从厂家获取
title            否    签字窗口标题，默认"电子签名"
showDialog       否    是否显示签字窗口，"1"显示（默认），"0"不显示
nOrgX            否    窗口左上角X坐标，-1为默认
nOrgY            否    窗口左上角Y坐标，-1为默认
nWidth           否    窗口宽度，-1为默认
nHeight          否    窗口高度，-1为默认
nImageWidth      否    签名图片宽度，-1按原比例
nImageHeight     否    签名图片高度，-1按原比例
nConfirmTimeout  否    签名超时时间(秒)，默认20
penColor         否    笔迹颜色，"000000"为黑色（默认）
fingerCap        否    采集指纹模式，"1"开启（仅ESP370D型号）


七、注意事项
------------------------------------------------------
- 连接地址：ws://127.0.0.1:29999/（本机，不需要改）
- 浏览器要求：支持 WebSocket 的现代浏览器（Chrome/Edge/Firefox）
- 密钥 key：sign.js 中已内置，直接使用即可
- 签名超时：nConfirmTimeout 控制，超时后自动关闭设备
- 断线重连：sign.js 的 onclose 已内置自动重连逻辑
- 如果 showDialog 设为 "0"，需要自行在页面内嵌签名窗口
- 可通过 HWGetSign 的 type 参数指定返回格式（base64、url、binary）
